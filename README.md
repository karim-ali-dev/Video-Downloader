# 🎬 Video Downloader

برنامج تحميل فيديوهات وصوتيات من يوتيوب وكل المواقع المدعومة من **yt-dlp** — بواجهة عربية جميلة وسريعة، ومجاني 100%.

---

## ✅ المميزات

- 📋 **لصق مباشر**: انسخ الرابط واضغط `Ctrl+V` (أو زر "لصق") ويتضاف تلقائيًا
- 🖼️ **صورة مصغرة** لكل فيديو بتظهر تلقائيًا
- 📦 **حساب الحجم فوريًا** قبل التحميل (الإجمالي لكل القائمة)
- 🔄 **تحميل متوازي**: حتى 3 فيديوهات في نفس الوقت بدون تجميد الواجهة
- ⏸️ **إيقاف مؤقت / استئناف** لكل فيديو على حدة
- 🛑 **إيقاف** فردي لكل فيديو
- 📁 **اختر مجلد الحفظ** وتغيره بسهولة
- 📄 **قوائم التشغيل** بتتوسع تلقائيًا لفيديوهات منفصلة
- 🎨 واجهة داكنة عربية بالكامل

## 📥 التحميل للكمبيوتر (Windows)

تحمّل آخر إصدار من [Releases](https://github.com/karim-ali-dev/Video-Downloader/releases):

- ملف `VideoDownloader_PC_vX.X.X.zip` — فك الضغط وشغّل `VideoDownloader_Final.exe`
- **مهم**: احتفظ بمجلدات الـ ZIP جنب بعض (الـ exe بيحتاج `_internal` ومجلد `tools`)

## 🤖 التحميل للأندرويد (Termux)

التطبيق نفسه نسخة كمبيوتر، لكن تقدر تشغّله على أندرويد عن طريق **Termux**:

1. نزّل [Termux](https://f-droid.org/packages/com.termux/) من F-Droid
2. افتح Termux والصق الأمر ده:

```bash
curl -sL https://raw.githubusercontent.com/karim-ali-dev/Video-Downloader/main/install_android.sh | bash
```

3. هيقفلك على سطح المكتب، وبعدها شغّل `video-downloader` من Termux
   - انسخ رابط الفيديو، اكتب `dl <الرابط>` واتبع الخيارات

> 💡 بديل سهل: نزّل تطبيق **yt-dlp** من Termux مباشرة بعد التركيب

## ⚙️ التشغيل من الكود المصدري

```bash
pip install yt-dlp pillow
python video_downloader.py
```

- محتاج **FFmpeg** في `tools/ffmpeg` أو أي مكان، لو موجود على الجهاز هيتعرف تلقائيًا
