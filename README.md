# Video Downloader

برنامج سطح مكتب احترافي لنظام Windows لتحميل الفيديوهات والصوتيات من YouTube ومجموعة واسعة من المواقع المدعومة عبر `yt-dlp`، بواجهة عربية حديثة تركّز على السرعة، الاستقرار، وسهولة إدارة عمليات التحميل.

![واجهة Video Downloader](assets/screenshot.png)

## نظرة عامة

**Video Downloader** هو تطبيق مكتبي مصمم لتوفير تجربة تحميل عملية وموثوقة، مع دعم إدارة عدة روابط ومهام في الوقت نفسه، والتحكم في صيغة الإخراج والجودة ومكان الحفظ من خلال واجهة واحدة واضحة.

يعتمد التطبيق على `yt-dlp` كمحرك تحميل أساسي، مع استخدام `FFmpeg` لمعالجة الوسائط ودمج وتحويل الملفات عند الحاجة.

## المميزات الرئيسية

- **إدارة متعددة للروابط:** إضافة رابط واحد أو مجموعة روابط دفعة واحدة ومعالجة كل مهمة بشكل مستقل.
- **لصق سريع:** دعم `Ctrl+V` لإضافة الروابط مباشرة إلى قائمة التحميل.
- **تحميل متوازي:** تنفيذ عدة عمليات تحميل بالتوازي للاستفادة بكفاءة من سرعة الاتصال.
- **تحكم في الجودة والصيغة:** اختيار جودة وصيغة الإخراج المناسبة قبل بدء المهمة.
- **دعم صيغ متعددة:** التعامل مع صيغ الفيديو والصوت الشائعة مثل MP4 وMKV وMP3 وفقًا لما يوفره المصدر.
- **معالجة الوسائط:** الاستفادة من `FFmpeg` لدمج المسارات ومعالجة وتحويل الملفات عند الحاجة.
- **بيانات الوسائط:** دعم حفظ الصور المصغرة وبيانات الملف ووسوم الوسائط عند توفرها.
- **إدارة مستقلة للمهام:** متابعة كل عملية تحميل وإيقافها أو استئنافها أو إلغاؤها دون التأثير على باقي المهام.
- **دعم قوائم التشغيل:** تحويل عناصر قوائم التشغيل إلى مهام تحميل منظمة وإدارتها ضمن قائمة واحدة.
- **اختيار مسار الحفظ:** تحديد مجلد الإخراج وتغييره بسهولة من داخل التطبيق.
- **مركز نشاط واضح:** عرض حالة العمليات وسجل الأحداث والتقدم من خلال واجهة مخصصة للمتابعة.
- **استجابة الواجهة:** تنفيذ عمليات التحميل في الخلفية للحفاظ على سلاسة استخدام التطبيق أثناء العمل.
- **واجهة عربية كاملة:** تصميم RTL متكامل مع واجهة داكنة ومنظمة للاستخدام اليومي.
- **بنية قابلة للتطوير:** فصل واجهة الاستخدام عن محرك التحميل ومعالجة الوسائط لتسهيل الصيانة والتطوير المستقبلي.

## متطلبات التشغيل

- Windows 10 أو Windows 11 بنظام 64-bit.
- Python 3.8 أو أحدث عند التشغيل من المصدر.
- `yt-dlp`.
- `FFmpeg` لمعالجة ودمج وتحويل بعض صيغ الوسائط.

## تحميل النسخة الجاهزة

يمكنك تحميل أحدث إصدار من صفحة [Releases](https://github.com/karim-ali-dev/Video-Downloader/releases).

النسخة الجاهزة لا تتطلب إعداد بيئة Python لتشغيلها. بعد فك ضغط الإصدار، شغّل الملف التنفيذي الموجود داخل الحزمة مع الحفاظ على الملفات والمجلدات المرفقة بها.

## التشغيل من المصدر

استنسخ المستودع ثم ثبّت المتطلبات:

```bash
git clone https://github.com/karim-ali-dev/Video-Downloader.git
cd Video-Downloader
pip install -r requirements.txt
```

ثم شغّل التطبيق:

```bash
python video_downloader.py
```

إذا لم يكن `FFmpeg` متاحًا على النظام، ضعه داخل `tools/ffmpeg` أو أضفه إلى متغير البيئة `PATH`.

## الاستخدام

1. أضف رابط الفيديو أو مجموعة الروابط إلى حقل الروابط.
2. اختر نوع الملف والجودة المطلوبة.
3. حدد مجلد الحفظ.
4. فعّل خيارات بيانات الوسائط أو الصور المصغرة عند الحاجة.
5. اضغط `ابدأ التحميل` لمتابعة المهام من مركز النشاط.
