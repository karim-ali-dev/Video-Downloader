# Video Downloader

برنامج سطح مكتب احترافي لتحميل الفيديوهات والصوتيات من YouTube ومجموعة واسعة من المواقع المدعومة عبر `yt-dlp`، مع واجهة عربية حديثة وسريعة ومصممة للاستخدام العملي.

![واجهة Video Downloader](assets/screenshot.png)

## نظرة عامة

Video Downloader هو تطبيق Windows يركز على سرعة التحميل، سهولة إدارة الروابط، والتحكم في جودة وصيغة الملفات. يدعم معالجة عدة روابط ضمن قائمة واحدة مع الحفاظ على استجابة الواجهة أثناء تنفيذ عمليات التحميل.

## المميزات الرئيسية

- إضافة رابط واحد أو مجموعة روابط دفعة واحدة مع معالجة كل رابط بشكل مستقل.
- دعم اللصق المباشر باستخدام `Ctrl+V` وإضافة الروابط تلقائيًا إلى قائمة التحميل.
- تحميل متوازي لعدة ملفات لتحسين الاستفادة من سرعة الاتصال.
- اختيار صيغة الإخراج والجودة المناسبة قبل بدء التحميل.
- دعم صيغ الفيديو الشائعة مثل MP4 وMKV، وصيغ الصوت مثل MP3 حسب ما يوفره المصدر.
- عرض الصور المصغرة وبيانات الوسائط قبل وأثناء عملية التحميل.
- إضافة بيانات الملف والصورة المصغرة عند توفرها لدعم تنظيم مكتبة الوسائط.
- إمكانية إيقاف واستئناف عمليات التحميل وإدارة كل مهمة بشكل مستقل.
- إلغاء مهمة محددة دون التأثير على باقي عمليات التحميل.
- دعم قوائم التشغيل وتحويل عناصرها إلى مهام تحميل منفصلة.
- اختيار مجلد الحفظ وتغييره بسهولة من داخل التطبيق.
- شريط تقدم ومركز نشاط لمتابعة حالة عمليات التحميل.
- واجهة عربية بالكامل مع تصميم داكن مناسب للاستخدام لفترات طويلة.
- الاعتماد على `yt-dlp` كمحرك تحميل قوي وواسع التوافق.
- الاستفادة من `FFmpeg` لمعالجة ودمج وتحويل الوسائط عند الحاجة.

## متطلبات التشغيل

- Windows 10 أو Windows 11 بنظام 64-bit.
- عند التشغيل من المصدر: Python 3.8 أو أحدث.
- `yt-dlp`.
- `FFmpeg` لمعالجة بعض صيغ الفيديو والصوت.

## تحميل النسخة الجاهزة

يمكنك تحميل أحدث إصدار من صفحة [Releases](https://github.com/karim-ali-dev/Video-Downloader/releases).

النسخة الجاهزة لا تتطلب إعداد بيئة Python لتشغيلها. بعد فك ضغط الإصدار، شغّل الملف التنفيذي الموجود داخل الحزمة مع الحفاظ على الملفات والمجلدات المرفقة بها.

## التشغيل من المصدر

استنسخ المستودع ثم ثبّت المتطلبات:

```bash
git clone https://github.com/karim-ali-dev/Video-Downloader.git
cd Video-Downloader
pip install -r requirements.txt
```

ثم شغّل التطبيق:

```bash
python video_downloader.py
```

إذا لم يكن `FFmpeg` متاحًا على النظام، ضعه داخل `tools/ffmpeg` أو أضفه إلى متغير البيئة `PATH`.

## الاستخدام

1. أضف رابط الفيديو أو مجموعة روابط إلى حقل الروابط.
2. اختر نوع الملف والجودة المطلوبة.
3. حدد مجلد الحفظ.
4. راجع خيارات البيانات والصور المصغرة المتاحة.
5. اضغط `ابدأ التحميل` لمتابعة المهام من مركز النشاط.
